Simply Fit Gym Website
A premium, responsive single-page website for Simply Fit Gym, Ganakpatty, By Lane 6, Sivasagar, Assam, India.
Features
Sticky navigation with a mobile hamburger menu
Full-screen hero, About, Facilities, Why Choose Us, Reviews, Gallery, Membership CTA, Contact and Footer sections
Gallery with a keyboard-accessible lightbox
Scroll reveal animations (respects reduced-motion settings)
WhatsApp enquiry buttons with a pre-filled message
Click-to-call and Google Maps links
Contact form with validation that sends the enquiry through WhatsApp (no data is stored)
SEO title, meta description, Open Graph tags and local business structured data
Tech
Plain HTML, CSS and JavaScript in one file, with Tailwind CSS (CDN), Google Fonts (Bebas Neue and Inter) and inline Lucide-style SVG icons. No build step is needed.
Run locally
Open index.html in any browser. An internet connection is needed for Tailwind and the fonts.
Deploy
Works on any static host. For GitHub Pages: Settings → Pages, choose the main branch and the root folder.
